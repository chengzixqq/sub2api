# V2 渠道监控参数说明

本次配置扩展基于魔改 v0.2.15，保留已验收的卡片与交互动效。配置分为站点监控策略、探针目标、旧聚合兼容和本浏览器显示偏好。以下为源码默认值，不代表线上当前值。此次仅本地实现和验收，未保存生产配置、执行收费探测或部署。

## 站点监控策略

管理入口：渠道监控 → 监控设置 → 监控与阈值。使用 observation-config GET/PUT，站点所有者权限、版本冲突保护、保存后清概览缓存；原有 JSONB 配置继续使用，无新增数据表或迁移。

| 参数 | 默认 | 可设范围及作用 |
|---|---:|---|
| 真实请求采集 | 开 | 控制真实请求采集，也是探针运行的前置开关；不会自动打开付费探活 |
| 主动付费探活 | 关 | 需真实采集、付费探活、目标三个开关均开启；手动探测同样约束 |
| 额度监控 | 开 | 独立只读额度同步 |
| 发布模式 | shadow | shadow 使用旧聚合展示；live 对发布分组使用 compact 数据 |
| 发布分组 | 空 | 空表示全部分组，最多1000个；未发布分组继续旧聚合 |
| 页面刷新周期 | 60秒 | 30–300秒整数；通过概览响应传给管理端/用户端轮询，不改变聚合粒度 |
| 最少真实请求样本 | 50 | 1–1,000,000；不足时标记样本不足，不猜测健康 |
| 正常/警告可靠率 | 99% / 95% | 0 < 警告 < 正常 ≤ 100% |
| 首字延迟警告/严重 | 3000 / 10000ms | 0 < 警告 < 严重 ≤ 86,400,000ms，整数 |
| 流量证据有效期 | 300秒 | 60–3600秒；过期后可采用有效探针证据 |
| 探测连续失败阈值 | 2次 | 1–10；真实流量与探针证据仍分开显示 |
| 额度证据过期 | 600秒 | 300–3600秒；超过时效标记陈旧 |
| 探测间隔 | 900秒 | 60–3600秒；无近期流量且达到间隔时才自动探测，不承诺每个间隔必执行 |
| 探测超时 | 20秒 | 5–60秒；执行上下文、HTTP调用和数据库占用时限配套使用 |
| 单目标每日次数上限 | 96 | 1–1440；自动与手动探测共用预算 |
| 全站每日次数上限 | 1000 | 1–100000；UTC日重置，与目标预算同时约束 |

减少预算后已产生的调用不撤回；后续预约被限额拦截。预算按数据库事务原子预约，重复幂等请求不重复计数。间隔不是实时保证：调度每分钟检查，保留并发4、每轮最多8个的保护。

### 首字延迟覆盖规则

最多100条，平台/分组/模型精确匹配，空字段表示不限，至少填写一个。重复的选择器拒绝保存。优先级为：

平台+分组+模型 > 分组+模型 > 平台+模型 > 平台+分组 > 模型 > 分组 > 平台 > 全局阈值。

模型级规则影响模型明细；只有平台/分组规则可直接匹配不带模型名的渠道聚合，不将一个模型的阈值套给其他模型。

### 保持固定的运行边界

- 明细保留24小时；涉及去重、重放、分区清理与查询边界，不能只修改一个保存值。分钟聚合48小时、小时聚合30天按既有机制保留，不因显示设置删除历史。
- 额度只读同步使用既有5分钟最小间隔，避免扩大供应商API调用。
- 真实数据聚合粒度与查询范围配套；不把刷新间隔当作时间桶宽度。
- 探针输出采用既有最小文本策略，不开放任意付费提示词、敏感凭据或取消预算保护。
- 系统设置中的渠道监控入口总开关、V1/V2模式及数据可见性仍按既有权限生效。

## 探针目标

支持分组、精确模型名、协议（OpenAI Chat / Responses、Anthropic、Gemini）、启用开关。新目标默认关闭。模型、分组权限和支持协议由后端再次验证。目标保存冲突保留草稿，先重新加载最新版本再人工合并，不静默覆盖他人更新。

## 旧聚合兼容

这不是V1配置。原 V2 被动日志聚合保留启用开关、60/300秒聚合刷新、平台/模型/分组选择、计入健康判定的错误分类，以及旧评分样本、错误率、首字延迟、缓存命中率和三项权重。

权重为非负百分比且合计100%；缓存阈值0/0合法，表示不设缓存降级门槛。统一卡片包括 legacy 来源行都重新使用“监控与阈值”的可靠率和延迟规则；旧评分字段用于原 V2 输出。shadow 模式和 live 未发布分组仍受旧聚合数据选择影响。

## 显示偏好

紧凑/宽松密度、宽屏最大2/3/4列或自动、跟随系统/关闭动画、P95详情、默认模型展开、默认视图、默认时间范围、自动刷新开关。小屏自动减少列数。系统减少动态效果优先。偏好按账号、角色、工作区在本浏览器保存，身份切换清理旧筛选，不向服务器写入。

## 修复与验收

修复百分比0被默认值替换、空值与非法权重被静默纠正、未知错误分类静默丢弃、保存失败/版本冲突丢草稿、刷新保存后页面仍固定60秒、默认视图与过时layout偏好脱节，以及探针历史窗口不足以判定默认两次失败的问题。历史JSON缺少新增字段时补默认值；旧客户端保存未提供的新增字段保留当前值，显式非法值拒绝。旧聚合设置300秒刷新时，采集陈旧判定也随周期调整，避免正常数据被每2分钟误报陈旧。

本地验收入口：`http://127.0.0.1:3015/monitor-preview.html`。显示偏好直接改变示例卡片；“配置参数验收”复用真实表单与校验，保存仅在内存保留、跨页签保留，重载页面重置。付费探测在预览禁止执行；示例健康数据不根据试填阈值重新计算。实际运行语义由前后端回归验证。
